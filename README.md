# 📖 Overview

SmartAttend is an AI-powered attendance management system developed to automate classroom attendance using **Face Recognition**.

The application provides a secure administrator dashboard where users can:

- Register students
- Capture facial data
- Train an AI recognition model
- Mark attendance automatically
- Store attendance history
- Send monthly attendance reports through email

# 🚀 Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/st-devworks/Smart-Attend.git
```

## 2️⃣ Move into Project Folder

```bash
cd Smart-Attend
```

## 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

## 4️⃣ Start Application

```bash
streamlit run app.py
```
