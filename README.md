# 🎓 SmartAttend

> AI-Powered Face Recognition Attendance Management System built using Python, Streamlit, OpenCV, and SQLite.

---

## 📖 Overview

SmartAttend is an AI-powered attendance management system that automates classroom attendance using Face Recognition technology. The system provides secure administrator access, student management, AI model training, attendance tracking, attendance history, and automated email reports.

---

## ✨ Features

- 🔐 Secure Admin Login
- 👨 Student Management
- 📷 Face Registration
- 🧠 AI Model Training
- ✅ Face Recognition Attendance
- 📜 Attendance History
- 📧 Monthly Email Reports
- 🔍 Search Students
- ✏️ Edit Student Details
- 🗑️ Delete Students

---

## 🛠️ Tech Stack

- Python
- Streamlit
- OpenCV
- SQLite
- Pandas
- Pillow
- SMTP (Gmail)
- LBPH Face Recognizer

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/st-devworks/Smart-Attend.git
```

### Move into Project

```bash
cd Smart-Attend
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
streamlit run app.py
```
